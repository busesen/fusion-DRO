# Intersecting Wasserstein Balls (Contextual Bandits)

Code for Excel-driven offline contextual bandit training with:
- Pooled Wasserstein DRO baseline
- Affine approximation for intersection of K Wasserstein balls
- SAA and one-level MLMC gradient estimators
- SGD/Adam optimization
- Out-of-sample evaluation on test counts

Main entry point:
- `run_intersect.py`
